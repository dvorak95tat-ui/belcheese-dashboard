# Беловежские сыры · ежедневная аналитика

Интерактивный дашборд производства и продаж молокозавода по выгрузке 1С
(`отчет в 1с.xlsx`, лист TDSheet, период 01.11.2026–22.11.2026).
Три раздела в боковой навигации: **Производство**, **Продажи**, **Сырье**.
Оформление: тёмная тема «хвоя + золото», графики Plotly и ECharts
(sankey-баланс, календарь-хитмап, потоковая диаграмма выпуска).

## Что показывает

- **KPI-карточки** с дельтой к предыдущему полному дню и спарклайнами.
- **Производство:** баланс молока (sankey: сыр / фета / масло / ГХИ / сыворотка / пахта / обрат + невязка),
  календарь выпуска сыра, ритм выпуска по дням, спарклайны и рекорды по продуктам.
- **Продажи:** отгрузки по продуктам (тн), прибыль и рентабельность по дням с подсветкой убыточных дней,
  остатки на конец дня, покрытие запасом в днях отгрузок.
- **Сырье:** приёмка молока, сортность в тоннах, календарь приёмки,
  связь закупочной цены и доли Экстра (пузырьковая диаграмма), цена с отметками мин/макс.
- Фильтр периода, переключатель учёта неполного последнего дня, экспорт CSV.

## Данные и правила расчёта

- Источник — `отчет в 1с.xlsx`, лежит рядом с `app.py`.
- Парсер сам находит строку с датами и режет секции по якорям
  («Произведено,», «Остатки на конец дня», «Продажи,», «Рентабельность»),
  показатели сопоставляются по имени внутри секции — одинаковые имена
  («сыр, тн», «фета, тн», «масло, тн») в выпуске, остатках и продажах не путаются.
- «в т.ч.» вычитается: сыр весовой = сыр − фасованный; масло сливочное = масло − ГХИ.
- Доля Экстра считается взвешенно по зачетному весу (сумма процентов ≠ тонны).
- 22.11 — неполный день (молоко 51 тн, сыр −1.3 тн, корректировка):
  исключается из дельт; в суммах учитывается по переключателю в сайдбаре.
- В календарях в клетке — число дня; количество (тн) видно при наведении и цветом клетки.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется на http://localhost:8501.

## Публикация

- **Hugging Face Spaces (без GitHub):** создать Space с SDK = Streamlit,
  загрузить через браузер файлы `app.py`, `requirements.txt`, `отчет в 1с.xlsx`, `README.md`.
  Ссылка: `https://<владелец>-<имя-space>.hf.space`.
  Данные конфиденциальные: Settings → visibility = Private, коллег добавить в collaborators.
- **Временная ссылка с своего ПК (без аккаунтов):** `link_ssh.bat` или `link_cloudflared.bat` —
  публичный URL действует, пока открыто окно туннеля.

## Примечания

- Тема задаётся в `.streamlit/config.toml`; кастомные стили (карточки, шапка, легенды) — в CSS внутри `app.py`.
- Если файл данных отсутствует или повреждён, приложение показывает понятную ошибку и не падает.
